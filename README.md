# 📝 Real-Time Character Counter

A simple and interactive character counter built using HTML, CSS, and JavaScript. It allows users to type a message in a text area while displaying the number of characters entered and the remaining characters in real time.

## ✨ Features

- **Text Area:** Allows users to type a message.
- **Real-Time Character Counter:** Updates the character count as the user types.
- **Character Limit:** Restricts input to a maximum of 200 characters.
- **Remaining Characters:** Displays how many characters are left.
- **Warning Message:** Shows a warning when the character limit is reached.
- **Responsive Design:** Provides a simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📚 What I Learned

- Creating and styling an HTML text area.
- Selecting HTML elements using JavaScript.
- Handling the `input` event.
- Updating content dynamically using `textContent`.
- Tracking character length using the `length` property.
- Implementing a character limit and warning message.

## 🚀 How to Use

1. Open the character counter webpage.
2. Type a message into the text area.
3. View the typed and remaining character counts in real time.
4. The text area prevents additional characters beyond the 200-character limit.
